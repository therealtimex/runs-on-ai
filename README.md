# How RealTimeX runs on AI

A one-page site for the Viet Nam–Bay Area Business Forum 2026 (Nov 19, 2026). People reach it from a QR code.

- Source: `site/index.html`, a single file with no build step. Language is EN/VI (switch with `?lang=vi`).
- Deploy: GitHub Pages runs on every push to `main` (`.github/workflows/pages.yml`).
- The evidence and caveats behind each number are in `realtimex-gtm/conferences/vn-ba-business-forum-2026/evidence-pack.md`.
- Never publish client names, customer chats, pricing, personal data, or anything under the ops team's `private/` folders.
